# Sitio atiktechmx.com

## Estado y avance

El avance de este proyecto se lleva en `ESTADO.md` siguiendo `METODO-AVANCE.md`.
Al empezar una sesión: leé ambos y mantené `ESTADO.md` al día (capacidades + scorecard).

Antes de trabajar, leé también `SIGUIENTES-PASOS.md` — análisis del estado y la dirección de este proyecto (qué cerrar, la Base del repo pendiente, decisiones de negocio abiertas).
